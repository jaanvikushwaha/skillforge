📄 Complete Resume Building Guide

Write a Resume That Gets Interviews

Master formatting, bullet writing, ATS optimization, and project-based evidence.

The Resume Formula That Works

A strong student resume follows this structure:

Header → Education → Experience → Projects → Skills → Links

Simple, organized, and scannable in 6 seconds.

Section Breakdown: What Each Part Should Say

1. Header (Name & Contact)

Format:

Alex Chen
(555) 123-4567 | alex.chen@email.com | LinkedIn.com/in/alexchen | GitHub.com/alexchen | Portfolio.com

✓ Do: Include all ways to contact you. Keep it clean — one line is best.

✗ Don't: Include photo, personal pronouns, or "Objective" statement.

2. Education

Format:

Bachelor of Science in Computer Science
University of California, Berkeley | Graduating May 2024
GPA: 3.7 | Relevant Coursework: Data Structures, Algorithms, Web Development, Databases

✓ Do: Include graduation date, GPA (if 3.5+), relevant courses, and honors.

✗ Don't: List high school. If you have work experience, education goes second.

3. Experience / Projects (Most Important)

Use this format for internships, part-time work, and projects:

[Company/Project Name] — [Your Role] | [Dates]
• [Action verb] [what you did] [result/impact with number]
• [Action verb] [what you did] [result/impact with number]
• [Action verb] [what you did] [result/impact with number]

4. Skills

Format:

Languages: Python, JavaScript, Java, SQL
Frontend: React, Vue.js, Tailwind CSS, HTML/CSS
Backend: Node.js, Express, Django
Tools & Platforms: Git, Docker, AWS, Figma

✓ Do: Group by category. Only list skills you've actually used.

5. Links Section

Optional but recommended:

Portfolio: portfolio.com | GitHub: github.com/username

The Secret: Strong Bullet Points

Your bullet points are everything. They should tell a story of what you accomplished.

Formula: [Action Verb] + [What You Did] + [Measurable Result]

❌ Weak Bullet

"Worked on React projects"

→ Vague. No impact. Could mean anything.

✅ Strong Bullet

"Built real-time dashboard in React that reduced data load time by 40%"

→ Specific. Measurable. Shows value.

❌ Weak Bullet

"Used Python for data analysis"

→ Passive. No context. No result.

✅ Strong Bullet

"Analyzed 500K+ customer records with Python to identify trends, enabling 15% increase in sales"

→ Active. Specific. Shows impact.

Action Verbs to Use:

Built • Designed • Developed • Implemented • Created • Optimized • Reduced • Increased • Automated • Improved • Launched • Managed • Collaborated • Solved • Analyzed • Debugged

How to Write Project Bullets (For Students)

No internship yet? That's fine. Use projects and academic work.

Template for Project Bullets:

Project: [Project Name] | [Tech Stack] | [Link]
• Developed [what you built] that [what it does/solves]
• Implemented [specific feature] using [tech], improving [metric] by X%
• Deployed to [platform], serving [number] users/requests

Real Example:

Project: Smart Study Tracker | React, Node.js, MongoDB | github.com/yourname
• Developed full-stack web app helping students track study goals with real-time progress visualization
• Built REST API backend handling 1000+ daily requests; optimized queries reducing response time by 45%
• Designed responsive UI with React and Tailwind CSS; tested on 3 browsers and mobile devices
• Deployed to Vercel; accumulated 200+ active beta testers with 4.8/5 satisfaction rating

ATS Optimization (So Computers Don't Filter You Out)

Applicant Tracking Systems scan your resume before humans see it. Make sure you pass the robot test.

✓ ATS-Friendly

  • Use standard formatting: Arial, Calibri, or Times New Roman (avoid fancy fonts)
  • Use .docx or .pdf (check the job posting for format requirements)
  • Simple section headers: Education, Experience, Skills (not creative names)
  • Match job keywords: If they ask for "React," say "React" (not "JavaScript frameworks")
  • Use bullet points not paragraphs
  • No text boxes, images, or graphics — ATS can't read them
  • One column layout — two columns confuse ATS

✗ ATS-Unfriendly

  • Fancy fonts or colors — ATS reads plain text only
  • Tables or text boxes — Use bullet points instead
  • Headers like "Core Competencies" — Stick to standard headers
  • Custom graphics or logos — ATS skips them
  • Abbreviations ATS won't recognize — Write it out first, then abbreviate
  • Inconsistent formatting — Use consistent spacing and bullet style

Pro tip: Before submitting, copy your resume text into Notepad. If it still reads well and makes sense, you're good for ATS.

Resume Length & Format

Students (0–1 Year Experience)

Length: 1 page

Focus: Education, projects, skills, internships/part-time work

Rule: Keep it SHORT. Quality over quantity.

Recent Grads (1–3 Years)

Length: 1 page (sometimes 1.5)

Focus: Internships, projects, full-time work

Rule: Still keep it tight. Recruiters spend 6 seconds scanning.

Formatting Tips:

  • Margins: 0.5–1 inch on all sides
  • Font size: 10–12pt for body text, 14–16pt for name
  • Line spacing: 1.0 or 1.15 (single or slightly more)
  • Bold: Company names, project titles, section headers
  • Dates: Align to right or use consistent format (e.g., "May 2023 – Aug 2023")

Common Mistakes to Avoid

  • ❌ Typos or grammar mistakes — Proofread 3 times. Use Grammarly.
  • ❌ "Objective" statements — Skip it. They're outdated.
  • ❌ Personal info like age or photo — Only include name and contact.
  • ❌ Lying or exaggerating — They WILL verify. Be honest.
  • ❌ Vague bullet points — Use numbers and specific results.
  • ❌ Inconsistent formatting — Same font, same bullets, same date format throughout.
  • ❌ Not tailoring your resume — Adjust for each job, highlight relevant skills.

Tailoring Your Resume for Each Job

Don't send the same resume to every job. Spend 5 minutes customizing it.

How to Tailor:

  1. Read the job description. Highlight 5–10 key skills they want.
  2. Reorder your experience. Put the most relevant work first.
  3. Match keywords. If they say "React," use "React" (not "frontend frameworks").
  4. Emphasize relevant projects. Move your best relevant project higher.
  5. Add relevant skills to your Skills section. Make sure your top skills match their needs.
Example:

Job posting mentions: React, API design, database optimization

You should:
— Move React projects to top
— Highlight bullet about "optimized database queries"
— Make sure React is listed in your Skills section

Final Checklist Before Submitting

  • □ No typos or grammar errors (read it aloud)
  • □ All dates are consistent and correct
  • □ Bullet points start with action verbs
  • □ Every bullet includes a specific result or number
  • □ Formatting is consistent (fonts, spacing, bullets)
  • □ Contact info is correct and complete
  • □ Customized for the job (keywords match job posting)
  • □ Fits on 1 page (or 1.5 max if you have experience)
  • □ Saved as PDF or .docx (check job posting)
  • □ Filename is professional: "FirstName_LastName_Resume.pdf"
